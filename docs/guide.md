# 使用教程

从启动到导出成片，完整走一遍。第一次用大概需要 20 分钟准备（主要花在注册各家账号上），
之后每次创作就是"说一句话"的事。

## 第一步：启动

按 [README 的快速开始](../README.md#快速开始) 把后端和前端跑起来，打开 <http://localhost:5173>。

登录页填任意账号密码即可进入 —— 开源版是纯本地运行，没有账号体系。
软件、key 和你的作品全都在自己电脑上。

## 第二步：配置 API Key

首次进入会弹出**配置向导**，跟着两步填：

1. **大模型** —— 导演 / 编剧 / 分镜的大脑
2. **图片生成** —— 智谱（画场景道具）+ Seedream（画角色关键帧），**两个都要**

向导之外还要自己去「系统设置 → **视频生成**」选一个视频服务：火山方舟 Seedance，或者本地 ComfyUI。

每家怎么注册、key 在哪找，看这篇：[**怎么获取 API Key →**](api-keys.md)

音乐（ElevenLabs）是可选的，跳过也能出片，只是没 BGM。
之后随时可以在「系统设置」里补。

## 第三步：说一句话，开始创作

在聊天框里描述你想拍什么，比如：

```
拍一个 2 岁小姑娘和小猫在客厅玩耍的温馨短片，30 秒左右，竖屏
```

AI 导演会追问几个问题（时长、调性、横竖屏等），聊清楚之后它就自动往下做了。

💡 说得越具体越好：角色几个人、什么场景、什么情绪、多长时间。

## 第四步：跟着流程一步步确认

画布上会长出一条流水线，**每一步都要你点「确认」才会往下走** —— 不满意就点「重跑」。

| 阶段 | 产出 | 你要做的 |
| --- | --- | --- |
| **剧本** | 标题、一句话梗概、分场 | 看一眼，不满意让 AI 改 |
| **美术设定** | 角色三视图、场景图、道具图 | 确认每张图；不喜欢就重跑那一张 |
| **分镜** | 每个镜头的画面描述、时长、运镜 | 确认镜头表 |
| **关键帧** | 每个镜头的首帧画面 | 确认；这步决定了视频长什么样 |
| **视频** | 每个镜头的视频片段 | 确认；用 Seedance 时这一步按秒计费，是最花钱的一步 |
| **合成** | 拼接 + 配乐的成片 | 导出 |

**角色怎么保持一致？** 关键帧和视频都会参考美术阶段确认过的角色三视图，
所以要先把三视图做到满意再往下走。

## 第五步：拿到成片

合成完成后可以直接下载。所有素材和成片都存在你自己电脑上：

- 源码运行：`backend/output/`（可以用环境变量 `OCTOPUS_OUTPUT_DIR` 改位置）
- 桌面版：`%LOCALAPPDATA%\Octopus\output\`

## 关于费用

| 花在哪 | 付给谁 | 大概 |
| --- | --- | --- |
| 大模型、图片、音乐 | 各厂商（用你自己的 key） | 一集几元 |
| 视频 | 火山方舟（Seedance，按秒计费） | 以官方价格为准 |
| 视频 | 本地 ComfyUI | 不花钱，吃显卡 |

## 常见问题

### 生成的角色前后长得不一样

确认**美术阶段的角色三视图**已经生成并确认过 —— 后续镜头都以它为准。
如果三视图本身就不理想，先把它重跑到满意再往下走。

### 视频变成了一张静态图 / 提示"占位"

视频服务调用失败时，节点会降级成占位片段，并在结果里写明原因。
常见的是：视频 key 没填 / 欠费 / 没开通 Seedance 模型，或者本地 ComfyUI 没起来。
修好后在那个镜头上点「重跑」即可。

### 某一步卡住不动

先看该节点有没有报错提示。常见原因：某家 API key 失效 / 欠费、网络不通。
去「系统设置」对应分类点「测试连接」能快速定位。

### 想改中间某一步

直接在那个节点点「重跑」。注意**改了上游会让下游失效**（比如重跑分镜，后面的关键帧和视频要重做）。
