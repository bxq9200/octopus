### 视频中转 + credits（2026-07-22 上线）
- **定价 0.8 元/秒**：`1 credit = 1 分(0.01元)` → `80 credits/秒`；新用户送 400（一条 5s 试用）。
- **钱三规矩**：提交查余额不够→402；**成功才扣费**（失败不扣，真实 SDK 缺失失败时余额纹丝不动，已验）；**扣费幂等**（`credit_ledger (reason=video, ref=task_id)` 唯一键）。任务归属校验、字节不过服务器（客户端直连蚂蚁 CDN 下载）。
- **实测真实出片**：t2v 4s → 232s succeeded → alipayobjects CDN URL → 扣 320 → 客户端下载 2.29MB。
- **充值 MVP**：`POST /v1/billing/grant`（X-Admin-Token 鉴权，**用户 JWT 越权→403**）+ `/v1/billing/balance`/`history`；前端设置「部署模式」tab 显示余额。**自动支付是独立阶段**。
- **企业凭据/SDK 上云**：`secrets.env` 存 antchain AK/SK；蚂蚁 AIGC SDK 五包从本地 site-packages tar 传服务器 venv（PyPI 没有）+ `pip install aiohttp requests`。详见 [[octopus-cloud-prod-server]]。
- 验收：`_verify_video_credits.py`（不烧钱）+ `_verify_billing.py`。

**线上地址**：`https://api.<你的域名>`（`GET /health` 可看版本、agent 列表、smtp/licensing 就绪状态、授权公钥）

## 三、几个关键设计（改之前先读）

**1. 云端服务内部强制 `local` 模式 —— 否则递归调用自己。**
`BaseAgent.run()`/`chat()` 里有 cloud_client 分叉；云端若也是 cloud_client，跑 agent 会再往"云端"发一次 → 打回自己。
`cloud/main.py` 在 import `app.*` **之前**就钉死 env，import 后再钉一次 settings。

**2. LLM key 用完即弃。**
用户的 key 随请求转发上来，用 `runtime_config.llm_override`（ContextVar）压进请求作用域，**不落库、不写日志**。
ContextVar 保证并发请求互不串号。云端日志只记 `{agent_type, entry, provider, model, payload_keys}`。

**3. agents 只有一份，在 `backend/app/agents/`，云端只 import。**
复制两份会漂移 → "云端出的分镜跟本地不一样"极难查。
**护城河靠打包时排除**：桌面端产物不得含 `backend/app/agents/` 与 `cloud/`，构建脚本**必须带断言**（产物里发现 agents 就中止）。**这条没做到，护城河就是裸的。**

**4. 前端不直连云端，走本地后端代理。**
只有本地后端知道网关地址、也只有它能把 token/授权落进 `user_settings`。前端只面对一套 API，顺带免 CORS。

**5. 登出必须同时清 license。**
否则登出后本地还留着有效授权，能力照开。

**6. 授权签名对象 = payload 的 canonical JSON**（`sort_keys=True, separators=(",", ":")`）。
云端 `licensing.py` 与客户端 `entitlements.py` **必须严格一致**，差一个空格全盘验不过且报错毫无线索。
`/health` 暴露 `license_pubkey` 就是给你比对用的。

## 四、踩过的坑

| 坑 | 结论 |
|---|---|
| **部署模式优先级** | `user_settings("deploy","mode")` **>** `config.DEPLOYMENT_MODE`。用户在设置页动过一次开关后，`OCTOPUS_DEPLOYMENT_MODE` 环境变量**永远压不过它**。脚本切模式必须同时设两处 |
| **本机 curl 测 HTTPS 会假失败** | 开发机 VPN 做 MITM，`curl`(schannel) 陷入无限 TLS 重协商 → HTTP 000。但**浏览器和 httpx（客户端真正用的库）都正常**。别用 curl 在本机判断云端 HTTPS 死活 |
| **中断 ≠ 撤销** | 中断工具调用时，已通过 SSH 发到服务器的命令**照样执行完**（实测：测试邮件因此发了两封）。远程副作用要在执行前拦 |
| **阿里云 ECS 封 25 端口** | SMTP 只能用 465(SSL) 或 587(STARTTLS) |
| **阿里云企业邮箱拒收本域不存在的信箱** | 往 `<你的域名>` 下不存在的地址发信会 `SMTPRecipientsRefused`（发外部邮箱正常）。发信失败时会删掉验证码记录并报 502，但**仍计入限频**（防刷） |
| **JWT_SECRET 不固定** | 每次启动随机生成 = 重启一次所有用户被登出。已固定在 `secrets.env` |
